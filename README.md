## 🚀 Main Project

A system that uses **Computer Vision** to recognize and classify garbage types from images.

**Technologies used**

* 🧠 Computer Vision for waste recognition
* ⚛️ Frontend: React
* 🌐 Backend: Node.js (REST API)
* 📦 Image processing model integration

**Features**

* Upload image of garbage
* Automatically classify waste type
* Display classification result
* Simple web interface for testing model
